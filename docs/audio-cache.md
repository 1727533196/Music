# 音频缓存与音质

播放条和歌曲详情页可切换标准、较高、极高、无损及 Hi-Res。偏好保存在设备设置中，默认无损；实际返回的音质受歌曲资源和账号权限影响。切换时保留进度及播放／暂停状态。

桌面端在接收音频流时同时写入 `<userData>/audio-cache/`，并行 Range 请求共用一次完整下载。只有完整接收的文件才登记到索引。下次同一账号、服务地址和音质下优先使用本地文件，避免再次申请播放链接和下载音频；缓存可跨重启复用，已有歌词快照也会复用。

缓存从本功能启用后的播放开始生成，不能仅凭以前的播放历史恢复音频。试听片段、无法确认音质的响应和非网易云 CDN 地址不登记为完整音频缓存。接口降级返回的音频按实际音质缓存，不能作为更高音质使用。歌曲列表查询、登录校验、播放记录同步等在线业务仍按原逻辑运行，这不是整个应用的离线模式。

音频容量上限为 2 GB，按最近使用时间淘汰；单文件超过 512 MB 时继续在线播放。设置 → 音质与缓存可刷新用量和清理音频缓存。清理会保留当前播放的文件，不删除账户、快捷键和其他设置；不同音质分别占用空间。

本地协议 `tinglan-audio://track/<随机令牌>` 提供完整及 Range 读取，渲染进程不能指定磁盘路径。索引不保存远程签名 URL、账号标识或服务地址明文，歌词快照单独保存。未完成下载以 `.part` 暂存，下次启动清理残片。缓存初始化、写入、读取或解码失败时回退到原在线音频来源；在线播放也失败时显示播放错误。

开发验证使用隔离的 Electron 实例和静音 WAV，覆盖渐进接收、分段读取、共享下载、重启后离线复用、账号／音质隔离、LRU、不完整文件拒绝、清理保留当前文件，以及真实播放器中的音质切换和损坏缓存回退。
