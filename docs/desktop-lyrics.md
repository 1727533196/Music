# 桌面歌词

在播放条或歌曲详情页点击“词”打开；“设置 → 外观与歌词 → 桌面歌词”可调整字体、字号、宽度、文字与高亮颜色、透明度及时间偏移。正偏移让歌词提前，负偏移延后。

- 默认快捷键：Ctrl + Alt + D 显示／隐藏，Ctrl + Alt + K 锁定／解锁。可在快捷键页修改；注册被其他程序占用时会显示失败信息。原 Ctrl + Alt + L 仍用于歌曲详情页。
- 非锁定时仅能从歌词文字或已显示的工具栏空白位置开始拖动；容器的空白区域不显示抓手、不触发操作面板，也不能拖动窗口。悬停歌词文字才显示操作面板，移到操作栏可继续使用。上下首使用播放器的图标动画，播放／暂停保留按压反馈和切换过渡。
- 只显示当前句，默认字号 28 px，不加文字阴影或描边。鼠标进入歌词本身即可显示覆盖整个歌词区域的操作面板，播放控制复用播放器图标。拖动采用指针捕获，避免原生拖动区域吞掉悬浮事件。
- 锁定后歌词区域鼠标穿透；悬停歌词文字时显示解锁按钮，只有该按钮接收点击，点击即可解锁。设置页和全局快捷键也可解锁。
- 默认未填充文字为 rgba(255, 255, 255, 0.3)，填充为 rgba(255, 255, 255, 1)。颜色选择保留各自透明度。
- 偏好与窗口位置保存在 userData/desktop-lyrics.json；启动恢复开关与锁定状态，显示器变化时纠正屏幕外位置，也可手动重置位置。
- 主窗口最小化后继续同步；关闭主窗口按原有退出方式同时销毁桌面歌词。桌面歌词覆盖普通窗口，不承诺覆盖独占全屏应用或系统安全界面。

## 实现

`src/main/desktopLyrics.ts` 创建无边框、透明、独立置顶窗口；专用 preload 仅暴露显示、偏好与控制操作，并校验 IPC 来源。两个窗口使用各自的 HTML 入口，桌面歌词不挂载应用路由、Pinia、音频实例和流体背景。

`src/renderer/src/utils/desktopLyrics.ts` 复用现有 HTMLAudioElement，把已解析的普通／逐字歌词转换成毫秒结构。歌曲或歌词变化时发送完整快照，打开时即时同步；播放状态每 250ms 校准，原生播放、暂停、缓冲、跳转和变速事件即时发送。歌曲修订号和进度序号防止迟到消息覆盖当前状态。

独立窗口通过本地单调时钟推进逐字高亮，暂停或缓冲时停止动画；最长推算 1 秒，来源中断后不持续漂移。长行按演唱进度横向移动，普通歌词按行切换并渐进高亮；加载中、无歌词和没有播放歌曲有独立显示。

启用期间关闭播放窗口的后台节流以保证最小化时持续校准，同时根据原生窗口可见性暂停不可见的详情流体背景。关闭桌面歌词后销毁窗口并停止周期同步，恢复后台节流。设置与窗口位置在主进程保存，不复制账户或音频链接。

Windows 高 DPI 下移动时显式传入固定宽高，避免原生 setPosition 的反复尺寸换算累积舍入误差；已验证连续 300 次移动和多次拖动后窗口尺寸稳定。

Electron 31 在 Windows 上调用 setFocusable(true) 会内部执行 setSkipTaskbar(false)，因此每次更改聚焦状态后恢复 setSkipTaskbar(true)，显示或聚焦窗口时也重新隐藏任务栏预览。保留独立窗口与置顶能力，不将歌词绑定为主窗口的子窗口。

Windows 上使用隔离 Electron 实例和静音 WAV 验证过：真实播放、逐字解析、暂停与暂停时跳转、音质切换保留进度、最小化同步、播放控制、穿透与解锁、长句、缓存歌词、重复打开、位置纠正和主窗退出清理。未新增单元测试文件。
