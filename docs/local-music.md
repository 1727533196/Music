# 本地音乐

顶部“本地音乐”入口无需登录。在桌面版中选择“添加音乐”导入多个文件，或选择“添加文件夹”递归扫描目录。导入只建立文件引用，不复制音频，也不上传文件。

## 上传到云盘

登录后，点击歌曲行的云上传图标，确认歌曲和当前音乐服务地址，即可将这首歌上传至当前账号的网易云音乐云盘。只有主动确认才会上传，导入、扫描及播放都不会自动上传。请仅上传你有权使用的音乐。

一次上传一首，最大 500 MB；文件通过现有音乐服务的 `POST /cloud` 接口流式发送，不需要额外部署上传服务器。远程音乐服务必须使用 HTTPS，本机服务可使用 HTTP。原文件不会移动或删除。

页面显示发送进度，发送完成后仍需等待云盘处理并确认成功。可以取消或在失败后重试；取消只停止本次请求，若服务已经收到文件，仍可能继续处理，请刷新云盘确认。切换页面不打断上传，切换账号或音乐服务则中止请求。成功后点击“查看云盘”查看；若云盘页面已打开，会自动刷新。

页面支持搜索、排序、全部播放、单曲播放和加入待播列表。列表采用固定行高窗口化，大量歌曲只渲染可见部分。重新进入页面或点击刷新时，按文件大小及修改时间增量更新；新增文件会加入列表，丢失文件会标记并提供“重新定位”。从资料库移除只删除索引，原文件保留；目录刷新不会立即重新导入明确移除的文件。

## 播放与歌词

- 本地歌曲与在线歌曲共用音频元素、播放队列、进度和音量控制、快捷键及桌面歌词。
- 本地歌曲使用文件原始音质，音质按钮展示格式、码率、采样率及位深；在线音质设置不会重新加载本地音频。
- 优先读取音频同目录、同名的 `.lrc` 或 `.LRC`，支持 UTF-8、UTF-16 LE 和 GB18030；没有同名歌词时尝试文件内嵌歌词。普通 LRC 按逐行时间轴显示，没有时间轴的内容在详情中静态显示。
- 封面按需读取内嵌图片，并依次尝试同名 `.jpg`、`.png` 及同目录 `cover.jpg`。没有封面时使用界面占位图。
- 本地歌曲不调用网易云的播放地址、评论、喜欢、动态封面或听歌上报接口。含本地歌曲的队列使用列表循环、随机或单曲循环。
- WAV、FLAC、MP3 已通过实际解码播放检查。导入还识别 M4A、AAC、OGG、Opus 和 WebM；实际播放取决于音频编码是否受当前 Electron 支持。

## 数据与边界

`src/main/localMusic.ts` 在 `app.getPath('userData')/local-library/index.json` 保存目录、元数据、排除项与稳定的 `local:<UUID>` 标识。前端队列保存本地 ID，重启后从主进程索引补全元数据；本地进度独立保存，恢复时保持暂停，用户点击播放后继续。

`tinglan-local://track/<UUID>` 和 `tinglan-local://cover/<UUID>` 只访问已登记文件。音频流支持 Range、HEAD 与取消读取，封面提供 MIME 和 CORS 头。preload 仅暴露按 ID 操作的 API，文件路径由主进程选框取得；IPC 只接受主窗口的主 frame。在线播放缓存的清理不会删除本地音频或本地资料库。

`music-metadata` 固定为 10.9.1，并在主进程中动态导入；没有新增原生编译依赖。不可打印的标签文本会回退为文件名或未知歌手、专辑，避免带控制字符的旧 WAV 标签显示乱码。
